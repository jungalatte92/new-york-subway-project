# The New York Subway Project

A static, accessible redesign of “Re-Mapping the (Invisible) Bodies of the New York Subway,” prepared for GitHub Pages.

## Local preview

Run a static server from this directory, then open the printed local URL.

```powershell
python -m http.server 8000
```

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**.

The expected public URL is:

`https://jungalatte92.github.io/new-york-subway-project/`
